## Sprint 2 — Tampilan Dasar Aplikasi

# Farhan Dwiyan Akbar - SRS 001: Login User
- Sebagai asisten/praktikan, saya dapat login ke aplikasi. Jika saya adalah praktikan saja, saya tidak dapat login sebagai asisten. Jika saya adalah praktikan dan asisten, saya dapat memilih peran setelah login, lalu diarahkan ke halaman yang sesuai dengan pilihan peran tersebut.
- Sebagai asisten/praktikan, saya dapat melihat umpan balik jika login tidak berhasil sehingga saya mengetahui penyebab kegagalan login dan dapat memperbaiki masukan saya.

# Rahmat Argyandha A. - SRS 002: Fitur-fitur Asisten
- Sebagai asisten, saya dapat melihat jadwal praktikum yang saya asistensi.
- Sebagai asisten, saya dapat membuka sesi saat praktikum dimulai dan menutupnya saat praktikum selesai.
- Sebagai asisten, saya dapat memantau kehadiran dengan melihat daftar praktikan yang sudah melakukan presensi beserta waktu kehadirannya. 

# Quinta Aurabiansyah - SRS 003: Fitur-fitur Praktikan
- Sebagai praktikan, saya dapat mengetahui jadwal praktikum saya dan detail sesinya. Detail sesi mencakup: mata kuliah, praktikum ke- …, nama praktikum, kelas (i.e. C1, C2, dst), ruang, waktu (tanggal dan jam), dan status sesi. Status sesi berubah sesuai dengan dibuka/ditutupnya oleh asisten.
- Sebagai praktikan, saya dapat melakukan presensi saat sesi dibuka. Presensi tidak dapat dilakukan dua kali pada sesi yang sama. Aplikasi mencatat waktu kehadiran dan memberikan umpan balik bahwa presensi berhasil. 
- Sebagai praktikan, saya dapat melihat catatan kehadiran saya sendiri.
